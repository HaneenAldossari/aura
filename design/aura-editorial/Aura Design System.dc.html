06 — Motion
There are exactly two pieces of ambient motion in Aura, both on Home: the starfield and the season-card fan. Everywhere else the interface holds still. No shimmer, scroll-reveal, parallax or floating elements on any screen, and nothing ambient behind the user's palette or their photo — those are the subject, and motion behind them reads as decoration.

Marked as built above means read from the component; proposed means this system is asking for it and the code does not do it yet. The idle drift is the one intended behaviour the code does not have yet: BounceCards ships an entrance and a hover response only, so today the starfield is the sole ambient motion. Add the drift as a continuous transform loop beneath the hover tweens. Separately, BounceCards does not check prefers-reduced-motion — its entrance and hover tweens run regardless. StarField does handle it. Under reduced motion the fan should render in its final position with no pop and no hover tween.
07 — Mirroring for Arabic
Every rule is full-width and every stack is symmetric, so the layout mirrors by flipping direction alone. Notes and quotes use logical borders (border-inline-start), never left. The 12-swatch band reverses order under RTL so swatch 01 stays at the reading edge. Percentages, hex codes and IDs stay LTR inside an isolated run. Letterspaced Latin caps labels become the Arabic equivalent at weight, not tracking — Arabic is never letterspaced.
