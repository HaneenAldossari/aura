# Fonts

Latin and latin-ext subsets, as served by Google Fonts, self-hosted so first
paint does not wait on a third party. `client/src/styles/fonts.css` declares
them and says why.

| family | licence |
| --- | --- |
| Cormorant Garamond | SIL Open Font License 1.1 — Christian Thalmann |
| Archivo | SIL Open Font License 1.1 — Omnibus-Type |
| IBM Plex Mono | SIL Open Font License 1.1 — IBM Corp. |

The OFL permits redistribution with the software; the reserved font names are
unchanged because the files are unmodified.
